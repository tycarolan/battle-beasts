# Specs

Feature specifications — the permanent record of **what** was built and why.
Written with `/0-write-spec` from `docs/SPEC_TEMPLATE.md`.

Specs outlive their implementation. If the code diverges from a spec, the spec
gets corrected to match what actually shipped.

Most changes to this app need no spec at all — see
[docs/SPEC_DRIVEN_DEVELOPMENT.md](../docs/SPEC_DRIVEN_DEVELOPMENT.md) for the
thresholds.
